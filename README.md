# web-corporativa-demo

Web corporativa de **Asesoría Demo** (empresa ficticia), hecha con [Eleventy](https://www.11ty.dev/).

- Contenido en Markdown en `src/contenido/`, datos en `src/_data/`, plantillas Nunjucks en `src/_includes/`.
- `npm run build` genera la web en `_site/`; `npm test` la compila y la comprueba.
- `staging` es preproducción y `main` es producción. Consulta [CONTRIBUTING.md](CONTRIBUTING.md).
